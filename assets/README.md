# Native app assets (source of truth)

Regenerated by `node generate-icons.mjs` (uses `assets/logo-crest.svg` + `public/icon-source.svg`).
These live in `assets/` (not `public/`) so they are **not** shipped in the web deploy.

| File | Size | Used for |
|------|------|----------|
| `icon.png` | 1024×1024 | App Store / Play marketing icon + `@capacitor/assets` icon source (opaque, no alpha) |
| `splash.png` | 2732×2732 | Native launch screen source (brand crest on app gradient) |
| `logo-crest.svg` | vector | The brand crest (faceted diamond + cage) — matches AuthPage + onboarding logo |

## At Capacitor packaging time

After `npx cap add ios` / `npx cap add android`, generate every icon + splash size in one command:

```bash
npx @capacitor/assets generate --iconBackgroundColor '#04080F' --splashBackgroundColor '#04080F'
```

(reads `assets/icon.png` and `assets/splash.png`; if `splash-dark.png` is absent it reuses `splash.png` for dark mode — correct here since the app is dark.)

## Location permission strings (add to the generated native projects)

The app uses `navigator.geolocation` (nearby courts/matches in `ClubPage.jsx`).

**iOS** — `ios/App/App/Info.plist`:
```xml
<key>NSLocationWhenInUseUsageDescription</key>
<string>Używamy lokalizacji, aby pokazać boiska i mecze w pobliżu.</string>
```

**Android** — `android/app/src/main/AndroidManifest.xml`:
```xml
<uses-permission android:name="android.permission.ACCESS_COARSE_LOCATION" />
<uses-permission android:name="android.permission.ACCESS_FINE_LOCATION" />
```
